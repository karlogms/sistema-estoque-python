# Sistema de Controle de Estoque em Python

Projeto pessoal desenvolvido durante meus estudos de Python e Análise e Desenvolvimento de Sistemas.

## Objetivo

Criar um sistema de controle de estoque para praticar lógica de programação e desenvolver habilidades em Python.

## Tecnologias utilizadas

- Python 3
- Visual Studio Code
- Git e GitHub

## Funcionalidades

- Menu interativo pelo terminal
- Opções para cadastro, listagem, busca e exclusão de produtos em desenvolvimento
- Prática de estruturas condicionais e repetição
- Manipulação de listas e dicionários

## Como executar

1. Instale o Python.
2. Abra a pasta do projeto no terminal.
3. Execute o comando:

   `py main.py`

## Status do projeto

Em desenvolvimento. Novas funcionalidades serão implementadas conforme minha evolução nos estudos de Python.
